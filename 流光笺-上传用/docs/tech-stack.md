# 技术方案说明

## 1. 推荐实现方案
建议使用 Python 作为主开发语言，配合 PySide6 构建桌面界面，使用 SQLite 保存本地数据。

## 2. 方案理由
- Python 学习成本较低，适合快速实现原型。
- PySide6 可提供较完整的窗口、悬浮窗、主题切换能力。
- SQLite 适合本地轻量任务数据存储，部署简单。
- 兼容 Windows，便于后续打包成可执行文件。

## 3. 组件建议
- GUI：PySide6
- 数据库：SQLite
- 配置文件：JSON 或 SQLite 配置表
- 打包：PyInstaller
- 日志与文档管理：Markdown + Python 脚本

## 4. 版本规划
- v0.1：基础任务 CRUD、今日任务展示、搜索。
- v0.2：悬浮窗和双击完成/删除。
- v0.3：主题切换、后台运行、细节优化。
