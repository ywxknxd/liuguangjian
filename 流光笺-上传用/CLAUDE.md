# CLAUDE.md

## 项目说明
- 项目名称：流光笺
- 目标：为 Windows 用户提供一款简洁、轻量的日常任务记录与悬浮查看工具。
- 现阶段优先级：先保证功能稳定、交互清晰、数据安全，再逐步扩展高级能力。

## 标准文件位置
- 需求说明：docs/requirements.md
- 技术方案：docs/tech-stack.md
- 设计规范：docs/design-spec.md
- 开发执行步骤：docs/development-steps.md
- 开发日志说明：dev-logs/README.md
- 每日开发日志：dev-logs/YYYY-MM-DD.md
- 日志更新脚本：tools/update_daily_log.py

## 工作说明
1. 每次开始开发前，先查看需求与设计规范，避免直接跳进实现。
2. 每次只推进一个小阶段，确保每一步都能验证、都能回退。
3. 每次工作结束时，更新当天的开发日志，记录完成事项与待办事项。
4. 代码或界面改动应尽量保持简洁，优先保证可用性与稳定性。
5. 如有新增需求，应先补充到需求文档，再开始实现。
