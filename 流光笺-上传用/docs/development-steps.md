# 开发执行步骤

## Phase 1：项目基础准备
- 创建项目目录结构。
- 建立需求、设计、技术与开发日志规范文件。
- 确定开发工具与运行环境。

## Phase 2：数据层与任务模型
- 定义任务字段：标题、日期、时间、优先级、状态、创建时间。
- 实现本地数据库存储。
- 完成新增、读取、编辑、删除功能。

## Phase 3：主界面开发
- 实现今日任务列表展示。
- 按时间升序排序。
- 增加搜索、置顶和删除操作。

## Phase 4：悬浮窗开发
- 实现悬浮窗窗口。
- 仅显示今天任务。
- 支持双击完成或删除。
- 支持置顶/置底与靠边隐藏。

## Phase 5：交互与视觉优化
- 实现浅色/深色模式切换。
- 优化任务完成后的展示状态。
- 完成基础错误提示与稳定性处理。

## Phase 6：打包与稳定性
- 测试功能流程。
- 输出可执行版本。
- 记录后续优化点。
