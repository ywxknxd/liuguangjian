# 设计规范

## 1. 视觉风格
- 以简洁、直观、轻量为核心。
- 主色以灰色、白色为主。
- 支持浅色模式和深色模式。
- 组件边界清晰，交互反馈明确。

## 2. 页面结构
### 主界面
- 顶部：标题与搜索框。
- 中间：今日任务列表。
- 底部：新增任务入口。

### 悬浮窗
- 仅显示今天的任务。
- 任务卡片支持双击触发完成或删除操作。
- 支持置顶、置底和边缘自动隐藏。

## 3. 任务卡片规范
- 标题清晰可见。
- 时间与优先级单独展示。
- 完成任务字体变淡，并显示勾选标记。
- 已完成任务显示在列表底部。

## 4. 交互规范
- 新建与编辑使用统一表单。
- 删除前应有确认提示。
- 搜索结果实时刷新。
- 主题切换应立即生效。
