# 项目开发需求说明

## 1. 项目目标
开发一款运行在 Windows 设备上的日常记录软件，帮助用户管理当天待办事项，界面简洁，操作直观，支持悬浮查看和本地保存。

## 2. 核心功能
- 创建日程：输入标题、日期、时间、优先级。
- 编辑日程：创建后可修改内容。
- 删除日程：仅支持手动删除。
- 任务状态：完成后显示为已完成，字体变淡，并显示勾选标记。
- 展示规则：任务只在对应日期当天显示。
- 今日任务视图：打开软件时默认查看今天的任务。
- 任务排序：按时间升序排列。
- 搜索：支持按关键词搜索任务。
- 悬浮窗：默认显示今天任务，支持置顶/置底和靠边自动隐藏。
- 后台运行：软件关闭后仍保持后台可用。

## 3. 用户体验要求
- 界面简洁，主色以灰白为主。
- 支持浅色模式和深色模式切换。
- 悬浮窗操作轻量，双击任务可完成或删除。
- 完成的任务显示在当天任务列表底部。

## 4. 数据要求
- 数据应本地存储，避免依赖云服务。
- 支持重启后仍保留已有任务。

## 5. 当前版本范围（MVP）
优先实现以下内容：
1. 创建、编辑、删除任务。
2. 今日任务展示与时间排序。
3. 任务完成状态展示。
4. 搜索功能。
5. 悬浮窗。
6. 主题切换。
7. 后台运行能力。
